# Where to Start

* Start with [`fts`](https://developer.apple.com/library/archive/documentation/System/Conceptual/ManPages_iPhoneOS/man3/fts.3.html). Determine if your recursive approach is made redundant by `fts`.
* If `fts` is what you think it is, do some practice usage with it.
* Practice some basic usage of [`copyfile`](https://developer.apple.com/library/archive/documentation/System/Conceptual/ManPages_iPhoneOS/man3/copyfile.3.html).
* Study the [bash `cp` command soruce code](https://github.com/coreutils/coreutils/blob/master/src/cp.c) to get some ideas
